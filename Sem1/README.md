# Analiză Statistică Teritorială (Semestrul 1)

Acest proiect realizează prelucrarea și analiza datelor economico-sociale din România pentru anul 2022.

## Cerințe implementate:
- Înlocuirea valorilor lipsă (`NaN`) cu media coloanei.
- Centrarea și standardizarea datelor (Z-score).
- Calculul matricelor de corelație și covarianță totale și pe regiuni.
- Testarea normalității (Shapiro, Kolmogorov-Smirnov, Anderson-Darling și Chi-pătrat manual).
